# ДомСтрой — MVP личного кабинета строительной компании

Статический фронт (GitHub Pages) + Supabase (Postgres, Auth, Storage, RLS).
Стек: vanilla JS (ES-модули), supabase-js v2 (CDN), без шага сборки.

## Возможности
- Публичный калькулятор стоимости дома + форма заявки
- Регистрация/вход (email + пароль), роли admin/client
- Кабинет клиента: свои проекты, этапы, фотоотчёты, платежи (только просмотр)
- Админ-панель: CRUD проектов/этапов/платежей, загрузка фото, заявки,
  редактирование коэффициентов калькулятора, статистика
- RLS: клиент видит только свои данные; фото — только admin и владелец проекта

## Подготовка

### 1. Supabase
1. Создайте проект на https://supabase.com (бесплатный тариф достаточен).
2. **SQL Editor** → вставьте всё содержимое `sql/schema.sql` → Run.
   Создастся: таблицы, RLS-политики, bucket `stage-photos`, триггер профилей, seed калькулятора.
3. **Authentication → Providers**: включите Email. Для MVP подтверждение email можно отключить
   (Authentication → Sign In / Providers → Email → отключить «Confirm email»).
