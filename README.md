# ДомСтрой — личный кабинет строительной компании

Сайт (GitHub Pages) + Supabase (Postgres, Auth, Storage, RLS).
Стек: vanilla JS (ES-модули), supabase-js v2 (CDN), без шага сборки.

## Возможности
- Сайт-лендинг с формой заявки (имя, телефон, email, комментарий)
- Регистрация/вход (email + пароль), роли admin/client
- Кабинет клиента: свои проекты, этапы, фотоотчёты, платежи (только просмотр)
- Админ-панель: CRUD проектов/этапов/платежей, загрузка фото, заявки, статистика
- RLS: клиент видит только свои данные; фото — только admin и владелец проекта

## Подготовка

### 1. Supabase
1. Создайте проект на https://supabase.com.
2. **SQL Editor** → вставьте всё содержимое `sql/schema.sql` → Run.
3. Затем выполните `sql/migration.sql` (поля цены/срока в заявках — необязательные).
4. **Authentication → Providers → Email**: для MVP можно отключить «Confirm email».
